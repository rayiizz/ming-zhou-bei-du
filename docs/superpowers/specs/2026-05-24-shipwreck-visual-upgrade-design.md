# 《明舟北渡》永乐号沉船案视觉升级设计

## 目标

本轮升级聚焦“永乐号沉船案”，目标是把当前可玩的 Demo 打磨成更接近正式网页对话游戏的视觉体验。重点不扩展剧情规模，而是强化外观设计、人物立绘、背景氛围、对话框演出和轻量动画，让项目在展示时形成“AI 衍生剧情 + 大运河文化 + 高完成度视觉”的第一印象。

## 视觉方向

采用“半写实国风游戏立绘 + 写实电影感大运河场景 + 案卷质感 UI”的混合方向。

- 画面基调：古代、悬疑、沉浸，不使用明显现代科幻或赛博 UI。
- 背景质感：偏写实电影场景，突出运河水面、码头、漕船、雾气和暮色光影。
- 人物质感：半写实国风立绘，保留游戏感和角色辨识度，避免过度卡通。
- UI 质感：对话框参考 3A 游戏低位叙事 HUD，同时加入宣纸、朱批、印章、案卷边框等古代案牍元素。

## 场景设计

剧情场景从普通码头升级为“夜色将临的徐州运河险段”。

关键画面元素：

- 远景：宽阔大运河水面、暮色天空、淡雾、远处城墙或码头建筑。
- 中景：漕船、停泊船影、灯笼、河面微光。
- 近景：湿润木栈道、粮袋、船板残片、绳索、打捞木桩。
- 氛围：沉船案发生后的压抑感，但仍能清楚看出“大运河”是主视觉核心。

背景可先用现有资源增强，也可后续生成一张新的“徐州运河险段夜幕码头”背景图。正式实现时，背景层应支持雾气、水光和轻微视差。

## 人物立绘

本轮至少升级两个核心立绘：

### 沈砚

主角身份为案卷整理者/临时巡检。视觉关键词：

- 年轻、冷静、克制。
- 青蓝色明代服饰，衣摆清爽，适合站在左侧。
- 手持札记、卷宗或笔。
- 气质偏理性调查者，不做夸张武侠造型。

### 王淮远

核心 NPC 为漕粮督运官。视觉关键词：

- 年长、稳重、有官场压力。
- 棕褐或暗红色明代官服，适合站在右侧。
- 手持账册、木牌或文书。
- 神情谨慎，既有责任感，也有被追责的紧张。

后续 NPC 可沿用同一立绘规范扩展，确保人物比例、光源方向、边缘处理和整体画风统一。

## 对话框演出

对话框升级为低位宽屏式叙事面板，参考 3A 游戏人物对话，但保留古代案卷材质。

结构：

- 左上角：说话人姓名。
- 名字下方或旁边：身份/情绪标签，例如“漕粮督运官 · 克制”。
- 中部：正文对话，支持淡入或轻量打字机效果。
- 下方或右侧：建议选项，hover 时金色描边、轻微抬升。
- 辅助区：自由输入和图鉴按钮弱化为工具操作，不抢主对话视觉。

行为：

- 当前说话人物高亮，非说话人物降低亮度、饱和度和透明度。
- NPC 切换时，右侧人物有轻微滑入和淡入。
- 对话更新时，对话框正文轻微淡入。
- 选项出现时 stagger 动画，形成层次感。

## 动画设计

动画以“沉浸”和“质感”为目标，不追求花哨。

- 背景雾气缓慢横移。
- 水面高光缓慢流动。
- 人物立绘轻微呼吸浮动。
- 当前说话人有微弱边缘光。
- 对话框出现和切换时使用短时淡入。
- 选项 hover 有金色描边、阴影和小幅位移。
- 打开图鉴时抽屉滑入，背景轻微压暗。

所有动画必须尊重 `prefers-reduced-motion`，在用户偏好减少动画时关闭或显著减弱。

## 组件与数据影响

本轮以视觉和交互演出为主，不改变核心剧情数据结构。

预计涉及：

- `DialogueScene.tsx`：增加说话状态、身份标签、场景层、演出类名。
- `styles.css`：重写沉船案场景、立绘位置、对话框、选项、动画和移动端布局。
- `public/assets/`：可能新增或替换背景图、沈砚立绘、王淮远立绘。
- 现有测试：保持主流程测试可通过，必要时更新文本查询，避免因纯展示结构变化导致测试脆弱。

## 移动端要求

移动端优先保证可读性和不遮挡。

- 立绘可保留半身，但不强求完整展示。
- NPC 切换按钮横向排列，避免覆盖对话正文。
- 对话框固定在底部，但允许内容区域滚动。
- 选项单列排列，按钮高度稳定。
- 背景仍保留大运河识别度，不使用过暗遮罩导致画面失去主题。

## 验证标准

实现后需要验证：

- 桌面端首页、案卷页、沉船案对话页、总结页无明显遮挡。
- 移动端首页和沉船案对话页文字横向可读，按钮不溢出。
- `corepack pnpm test` 通过。
- `corepack pnpm build` 通过。
- 浏览器截图确认人物左右布局、对话框低位、背景大运河元素清晰可见。

## 非目标

本轮不做以下内容：

- 不扩展多个新案卷。
- 不实现完整后端 AI 服务。
- 不增加复杂存档、账号、成就系统。
- 不重写现有调查状态机。
- 不加入过度现代化 UI 或科幻风格。
